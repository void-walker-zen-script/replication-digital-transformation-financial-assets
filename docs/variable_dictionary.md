# 变量字典

以下口径是复现起点，不代表已经与原论文完全一致。正式分析前应逐项核验论文定义、数据库字段和会计科目。

| 变量名 | 类型 | 初步定义 | 构造说明或注意事项 |
|---|---|---|---|
| `digital_index` | 核心解释变量 | 企业数字化转型指数 | 依据年报数字化关键词频次构造；候选形式为 `log(1 + count)`，最终按论文核验 |
| `financial_assets_ratio` | 被解释变量 | 金融资产总额 / 总资产 | 金融资产所含科目须按论文及会计准则统一 |
| `short_fin_assets_ratio` | 被解释变量 | 短期金融资产 / 总资产 | 可包括交易性金融资产等流动性金融资产，具体范围待核验 |
| `long_fin_assets_ratio` | 被解释变量 | 长期金融资产 / 总资产 | 可包括长期股权或其他长期金融投资，具体范围待核验 |
| `size` | 控制变量 | 企业规模 | 常用定义为 `ln(总资产)`；注意资产单位与正值检查 |
| `lev` | 控制变量 | 资产负债率 | 常用定义为总负债 / 总资产 |
| `roa` | 控制变量 | 总资产收益率 | 净利润或营业利润口径须按论文核验 |
| `growth` | 控制变量 | 企业成长性 | 常用营业收入增长率；需处理上一期为零或缺失的情况 |
| `cashflow` | 控制变量 | 经营现金流指标 | 常用经营活动现金流净额 / 总资产 |
| `firm_id` | 标识变量 | 企业唯一代码 | 建议保留前导零并统一为字符串 |
| `year` | 时间变量 | 会计年度 | 整数年份，与年报对应年度保持一致 |
| `industry` | 分类变量 | 行业分类 | 记录分类标准及版本，避免跨年口径不一致 |
| `soe` | 分组变量 | 国有企业标识 | 通常为国有控股取 1，否则取 0；最终定义待核验 |
| `region` | 分类变量 | 企业注册地或经营地区 | 明确省份、城市或东中西部层级及映射规则 |
