# 数据获取与合规说明

## 年报来源

上市公司年报可从巨潮资讯网、上海证券交易所、深圳证券交易所等公开页面获取。获取和使用时应遵守网站条款、访问频率限制、版权规则及学校或研究机构的合规要求。

本项目的下载脚本仅提供人工准备文件的接口说明，不自动爬取网站。

## 财务数据来源

财务数据可来自：

- CSMAR；
- WIND；
- CNRDS；
- 同花顺 iFinD；
- 依据公开财务报告手工整理的数据。

商业数据库数据须在有效授权范围内使用。不同数据库的字段定义、单位、复权方式和缺失值编码可能不同，使用前必须查阅数据字典。

## 不上传 GitHub 的内容

以下内容不得上传 GitHub：

- 上市公司年报 PDF；
- 从年报提取或清洗后的文本；
- 关键词计数明细；
- 财务原始数据和处理后的企业层面数据；
- CSV、XLSX、DTA、Parquet 等数据文件。

项目已将 `data/raw/`、`data/interim/` 和 `data/processed/` 全部写入 `.gitignore`。

## GitHub 可以保存的内容

GitHub 只保存：

- 数据处理和回归代码；
- 研究设计与变量说明文档；
- 不包含敏感数据或可反推企业明细的结果模板；
- 在许可范围内生成的汇总性图表或回归表。

提交前应运行 `git status`，确认没有原始数据、处理文本或受限文件进入暂存区。
