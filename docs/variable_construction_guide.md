# 变量构造指南

| 变量名 | 变量类型 | 中文含义 | 构造方式 | 数据来源 | Table 2 需要 | Table 3 需要 | 复现难点 |
|---|---|---|---|---|---|---|---|
| `firm_id` | 主键 | 企业唯一标识 | 统一为字符串并保留证券代码前导零 | 年报文件名、财务数据库 | 否 | 是 | 不同来源代码格式不同，前导零易丢失 |
| `year` | 主键 | 会计年度 | 从年报文件名和财务数据读取整数年份 | 年报文件名、财务数据库 | 否 | 是 | 年报披露年份与报告所属年份可能混淆 |
| `digital` | 核心解释变量 | 企业数字化转型指数 | 统计年报数字化关键词频率，当前框架取 `ln(1 + 关键词总次数)` | 年报文本 | 是 | 是 | 词典口径、文本清洗、OCR、年报长度和重复内容 |
| `fin1` | 被解释变量 | 短期金融资产配置 | （货币资金 + 以公允价值计量且其变动计入当期损益的金融资产）/ 总资产 | 财务报表或数据库 | 是 | 是 | 新旧会计准则科目映射、缺失值是否为零 |
| `fin2` | 被解释变量 | 长期金融资产配置 | （应收利息净额 + 应收股利净额 + 可供出售金融资产净额 + 持有至到期投资净额 + 长期股权投资净额 + 投资性房地产净额）/ 总资产 | 财务报表或数据库 | 是 | 是 | 科目跨期变化、净额口径、报表层级一致性 |
| `Size` | 控制变量 | 企业规模 | 总资产取自然对数：`ln(total_assets)` | 财务报表或数据库 | 是 | 是 | 总资产单位、非正值和币种一致性 |
| `LEV` | 控制变量 | 资产负债率 | `total_liabilities / total_assets` | 财务报表或数据库 | 是 | 是 | 负债及资产口径、极端值 |
| `ROA` | 控制变量 | 总资产收益率 | `net_profit / total_assets` | 财务报表或数据库 | 是 | 是 | 净利润口径、平均资产或期末资产选择 |
| `ListAge` | 控制变量 | 上市年龄取自然对数 | 当前框架为 `ln(year - listing_year + 1)` | 上市信息数据库 | 是 | 是 | 上市日期、重新上市和加一规则需按原文核验 |
| `TOP1` | 控制变量 | 第一大股东持股比例 | 直接使用 `largest_shareholder_ownership` | 股权结构数据库 | 是 | 是 | 0–1 与 0–100 单位、期末或平均持股比例 |
| `Indep` | 控制变量 | 独立董事比例 | `independent_directors / total_directors` | 公司治理数据库 | 是 | 是 | 董事人数时点、缺位董事和董事会调整 |

所有构造方式都必须结合原文、附录和数据库字段说明再次核验。脚本不会将缺失的会计科目
自动视为零，也不会自动修改比例单位。
