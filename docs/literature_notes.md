## 阅读原则

1. 区分论文作者的结论与本项目自己的推断；
2. 记录准确页码、表号和版本日期；
3. 不把相关性结果自动解释为因果效应；
4. 对关键词词典、样本筛选和财务科目映射保留可审查记录。
