# 复现计划

## 第一阶段：阅读论文与拆变量

- 通读论文正文、附录和变量定义；
- 记录样本期、行业排除、异常值处理和回归设定；
- 将每个变量映射到数据字段或文本处理步骤；
- 标注无法从论文确认的口径，避免自行补造设定。

## 第二阶段：准备年报文本

- 在遵守网站规则和版权要求的前提下获取年报；
- 建立 `firm_id-year` 文件命名规则；
- 检查 PDF 是否可提取文本、是否需要 OCR；
- 将原始 PDF 仅保存在本地 `data/raw/annual_reports/`。

## 第三阶段：构造数字化转型指数

- 确定关键词词典及分类；
- 清理页眉、页脚、目录和异常字符；
- 统计关键词频次并保留可审计的分类计数；
- 按论文口径进行对数化或标准化；
- 人工抽查部分年报，评估误匹配风险。

## 第四阶段：整理金融资产配置变量

- 核对样本期内会计科目名称变化；
- 按论文口径汇总短期和长期金融资产；
- 以总资产进行标准化；
- 检查单位、缺失值、极端值和合计关系。

## 第五阶段：合并企业-年份面板数据

- 统一企业代码和年份类型；
- 检查每张表的 `firm_id-year` 唯一性；
- 合并数字化指数、财务变量和企业属性；
- 输出合并诊断，不静默删除未匹配样本。

## 第六阶段：固定效应基准回归

- 运行企业固定效应和年份固定效应模型；
- 依次加入核心解释变量和控制变量；
- 按论文设定处理标准误；
- 保存不含敏感明细数据的回归表模板。

第一阶段复现不做 staggered DID，不把固定效应相关性结果表述为因果结论。

## 第七阶段：短期/长期金融资产分组回归

- 分别以 `short_fin_assets_ratio` 和 `long_fin_assets_ratio` 为被解释变量；
- 保持控制变量、固定效应和标准误设定一致；
- 比较系数方向、数量级和不确定性。

## 第八阶段：机制与异质性分析

- 依据论文原文确认机制变量和分组依据；
- 预先说明分组规则与样本变化；
- 可考虑所有制、行业、地区等异质性；
- 在数据与识别条件不足时，仅保留分析计划。

## 第九阶段：结果对比与复现报告

- 对比样本量、描述性统计、系数和标准误；
- 区分完全一致、方向一致和无法复现；
- 说明数据版本、变量代理和清洗差异；
- 记录所有限制，不将框架搭建写成成功复现。
