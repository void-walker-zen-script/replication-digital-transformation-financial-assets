# Table 2 描述性统计复现说明

## 1. 复现目标

本阶段的目标是使用本地准备的企业—年份面板数据，按照原文 Table 2 的变量顺序计算描述性统计，包括观测数（N）、均值（mean）、标准差（sd）、最小值（min）和最大值（max）。

这一工作用于检查样本结构、变量量纲和数据清洗口径是否与论文接近。当前项目不预填任何数值，也不在缺少真实数据时生成模拟结果。

运行命令：

```powershell
python scripts/05_descriptive_statistics.py
```

输入文件：

```text
data/processed/panel_for_replication.csv
```

输出文件：

```text
outputs/tables/table2_descriptive_statistics.csv
```

## 2. 需要的数据字段

输入文件必须包含以下字段：

| 字段 | 用途 |
|---|---|
| `firm_id` | 企业唯一标识 |
| `year` | 会计年度 |
| `fin1` | Table 2 金融资产配置变量之一 |
| `fin2` | Table 2 金融资产配置变量之二 |
| `digital` | 数字化转型指标 |
| `Size` | 企业规模 |
| `LEV` | 资产负债率 |
| `ROA` | 总资产收益率 |
| `ListAge` | 上市年龄 |
| `TobinQ` | Tobin's Q |
| `TOP1` | 第一大股东持股比例 |
| `Indep` | 独立董事比例 |

各字段的精确定义、单位、缩尾处理和样本筛选规则，应以论文正文、附录和原始数据字典为准。字段存在并不代表变量口径已经与论文一致。

## 3. 原文 Table 2 的变量顺序

脚本按以下顺序输出：

1. `fin1`
2. `fin2`
3. `digital`
4. `Size`
5. `LEV`
6. `ROA`
7. `ListAge`
8. `TobinQ`
9. `TOP1`
10. `Indep`

统计列顺序为：`N`、`mean`、`sd`、`min`、`max`。

## 4. 如何判断结果是否接近原文

复现结果不应只比较小数点后的数值，还应依次检查：

1. 各变量的 `N` 是否接近原文，以判断样本期、筛选规则和缺失值处理是否一致；
2. 均值和标准差是否处于相近数量级，以检查变量单位、比例表示和对数转换；
3. 最小值和最大值是否接近，以检查缩尾、异常值删除及边界处理；
4. `fin1`、`fin2` 和 `digital` 的构造口径是否与论文完全对应；
5. 控制变量是否使用相同定义，例如 `Size` 是否取自然对数、比例变量使用 0—1 还是百分数；
6. 若仍有差异，应记录数据库版本、会计科目映射、样本筛选和缺失值处理差异。

只有在变量定义、样本范围和清洗步骤均得到核验后，数值接近才具有可比意义。数值不一致也不应被隐瞒或人为调整。

## 5. 数据不公开声明

当前项目不会上传原始财务数据、上市公司年报、提取后的年报文本或处理后的企业层面微观数据。`data/raw/`、`data/interim/` 和 `data/processed/` 均由 `.gitignore` 排除。

Table 2 输出也属于本地生成结果。公开任何汇总结果前，仍需确认所用数据库许可、学校规定以及结果是否可能泄露受限信息。
