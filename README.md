# 企业数字化转型与金融资产配置复现项目

英文名：`replication-digital-transformation-financial-assets`

## 项目目标

本项目是一个面向本科生的实证论文复现训练框架，目标是逐步学习论文拆解、数据整理、变量构造、面板数据合并和固定效应回归。当前仓库仅搭建清晰、可扩展、可审查的工作流程，不声称已经完整复现论文，也不声称已经得到真实结论。

## 复现论文信息

- 题目：*Digital Transformation and Corporate Financial Asset Allocation: Evidence from China*
- 作者：Yundan Guo、Han Liang、Li Shen
- 来源：arXiv:2509.09095
- 提交日期：2025-09-11

论文中的变量定义、样本筛选和实证设定仍需结合论文正文、附录及可获得的数据逐项核验。

## 为什么选择这个题

企业数字化转型与金融资产配置同时涉及数字经济、公司金融和实体企业“脱实向虚”等重要议题。该题目适合本科生训练以下能力：

1. 从中文上市公司年报文本中构造数字化转型指标；
2. 从财务报表科目中整理金融资产配置变量；
3. 构建企业—年份面板数据；
4. 理解并实现企业固定效应和年份固定效应模型；
5. 区分复现框架、复现结果与因果识别结论。

## 研究问题

核心问题是：企业数字化转型程度是否与企业金融资产配置比例相关？进一步关注这种相关性在短期金融资产和长期金融资产之间是否存在差异，以及可能的机制和异质性。

## 数据来源

- 年报文本：巨潮资讯网、上海证券交易所、深圳证券交易所等公开页面；
- 财务数据：CSMAR、WIND、CNRDS、同花顺 iFinD，或依据公开财报手工整理；
- 企业属性：可由上述数据库或公开披露信息整理。

数据的具体样本期、筛选规则、会计科目映射和缺失值处理方案，需要在获得论文全文及合法数据访问权限后进一步确认。

## 当前复现范围

第一阶段只搭建固定效应回归框架：

```text
financial_assets_ratio
    ~ digital_index
    + size + lev + roa + growth + cashflow
    + firm fixed effects
    + year fixed effects
```

仓库同时预留短期/长期金融资产分组回归，以及机制与异质性分析接口。当前阶段不实施 staggered DID，也不把固定效应回归解释为已识别的因果效应。

## 不公开数据声明

本仓库不上传上市公司年报 PDF、年报处理文本、金融财务原始数据，以及任何 CSV、XLSX、DTA、Parquet 数据文件。`data/raw/`、`data/interim/` 和 `data/processed/` 已全部写入 `.gitignore`。GitHub 仅保存代码、说明文档和不含敏感数据的结果模板。

使用者应自行确认数据库许可、网站使用条款、版权和数据合规要求。
